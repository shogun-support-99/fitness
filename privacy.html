Privacy & data

The short version: it stays on your device.

IronLog has no account system, no backend and no analytics. Your training log is a document in this browser's local storage — written by you, readable by you, and removable by you. This page explains the details, including the parts a host or a browser handles for any website.

Last updated 4 November 2026

✓

At a glance

  • No account. No email, password or profile leaves the app.
  • No tracking. No analytics, advertising or third-party scripts.
  • Your copy. Export everything as one JSON file at any time.
  • Your call. Erase everything from Settings when you want it gone.

What IronLog stores

Everything is written to local storage in the browser you use. There is no server-side copy and no sync service. The app keeps:

  • ironlog.v1 — your workouts, sets, custom exercises and preferences (units, rest defaults, theme, instruction language, last backup time).
  • ironlog.sidebar — whether the desktop sidebar is expanded or collapsed.

The service worker also caches the app's own HTML, CSS, JavaScript, fonts and the exercise catalogue in Cache Storage, so the app can open offline. It caches only files served from this site; it does not cache your exported backups.

What is not collected

IronLog does not collect names, email addresses, account credentials, location, device fingerprints, workout contents or usage analytics. There are no cookies set by the app, no advertising pixels, no third-party scripts and no remote font or CDN requests. The app makes no network request with your training data.

Hosting and routine request data

The site is served by GitHub Pages. Like any web host, GitHub receives standard request information when your browser loads a page — such as an IP address, user agent, requested URL and time. That is ordinary web-server logging controlled by GitHub, not by IronLog, and it is not linked to your workout document. See GitHub's privacy statement for details.

Once the app is installed or cached, it can run without contacting the network at all. When it does update, it fetches the same static files from this site.

Backups, imports and erasing

Export JSON creates a file in your downloads folder containing your whole log. That file is yours; where you keep it is outside IronLog's control. Import JSON replaces the current log with the file you choose. Erase all data in Settings clears the app's local document.

Because the log is local-only, clearing site data, using a private window, or losing the device can remove it permanently. IronLog asks the browser for persistent storage where that is supported, but no web page can guarantee that a browser will never evict local data. Keep an exported backup if the log matters to you.

Not medical advice

IronLog records training. It does not diagnose, treat or prevent any condition, and its numbers — including estimated one-rep max and volume — are training estimates, not medical measurements. Strength training carries risk. Work within your limits and consult a qualified professional before changing your programme, especially if you are injured, pregnant or managing a health condition.
