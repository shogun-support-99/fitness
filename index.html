Questions, answered plainly.

The short answers, without the marketing.

Is IronLog really free?

Yes, and there is nothing to upsell. There is no account to subscribe to and no premium tier — the whole app is a static site.

Where does my data go?

Into this browser's local storage, on this device. Clearing site data removes it, and it does not sync between devices, so export a backup if your history matters.

Does it work offline?

Yes. After the first visit the app is cached, so it opens and logs sets without a connection. Exercise instructions download when you open them.

Which exercises are included?

1,316 MIT-licensed exercises from the public exercises-dataset, each with a Gym Visual demo and steps across 10 instruction languages. You can add your own.

Can I move my log to another device?

Export from Settings and import the same file anywhere. It is one JSON document containing every session, routine and setting.
